# Documentation Writer

**Development version: 1.1.0**

An agent skill for producing structured, accurate,
audience-focused technical documentation.

## Features

- Tutorial, how-to, reference, and explanation documentation.
- Clarification of audience, goals, and scope.
- Outline approval before full documentation.
- Markdown output.
- Contextual awareness of existing project documentation.

## Installation

Install this skill using GitHub CLI:

gh skill install l08041271-pixel/documentation-writer documentation-writer
